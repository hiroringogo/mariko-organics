# 管理者画面リニューアル計画

## 要件整理

### 1. 公開設定: 2段階公開に変更
- **会員先行公開** (`is_member_published`): ONにすると会員だけに見える
- **一般公開** (`is_published`): ONにすると全員に見える（会員にも当然見える）
- ロジック: 一般公開=trueなら全員に見える。一般公開=falseでも会員公開=trueなら会員だけ見える
- DB変更: `lessons`テーブルに `is_member_published boolean NOT NULL DEFAULT false` 追加
- フォームに2つのトグル表示
- 生徒側: 現時点では会員機能未実装なので`is_published`フィルタのみ維持。会員機能実装時に`is_member_published`対応を追加

### 2. 管理者TOP画面 — ダッシュボード化（フルリライト）
デザイン`it9Y3`ベース:

**ヘッダー:**
- 「管理者ダッシュボード」+ レッスン追加ボタン + ログアウト

**月選択:**
- 「2026年3月」← → で月を切り替え、選択月のレッスンのみ表示

**メトリクスカード（3つ）:**
- 今月のレッスン数
- 総予約数（confirmed）
- 稼働率（予約数/総定員）

**レッスンリスト（アコーディオン）:**
- カレンダーは不要、リストのみ
- 日付ごとにグループ化
- 各レッスン: 日付、タイトル、公開/下書きバッジ、予約数/定員
- アコーディオン展開で:
  - 予約者一覧（アバター付き、支払いステータスバッジ）
  - 編集/公開トグル/削除ボタン
  - キャンセルボタン → モーダル確認
- 最少催行人数未満のレッスンに警告カード

**データエクスポート:**
- 予約一覧CSV / 生徒一覧CSV / 全データダウンロード
- Supabase無料プラン対策として先生にバックアップを促す

### 3. レッスン追加フォーム
- 公開トグルを2つに変更:
  - 「会員先行公開」トグル
  - 「一般公開」トグル
- 一般公開ONなら会員公開も自動ON

### 4. .penデザイン更新
- `it9Y3` ダッシュボード: タブ切替を削除してリストのみに
- `GPuEa` フォーム: 公開トグルを2つに
- `Sm4oW` カレンダービュー: 削除
- `6ejHM` キャンセルモーダル: 維持
